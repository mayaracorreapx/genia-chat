# GenIA — chat de perguntas

Front em formato de chat que coleta o e-mail e a pergunta da pessoa e grava tudo na planilha **GenIA - Respostas** (Google Sheets) via Google Apps Script.

- `index.html` — o front (HTML/CSS/JS puro, sem build)
- `genia.png` — avatar da GenIA
- `Code.gs` — script colado no Apps Script da planilha (implantado como App da Web)

Para trocar a planilha/implantação, altere `SCRIPT_URL` em `index.html`.
